# Escala de Atendimento - SENAC (Web Interativo)

Aplicação web interativa para gestão automatizada da escala diária e mensal de funcionários do atendimento no Senac.

## 🚀 Como Hospedar no GitHub Pages

1. Crie um repositório público no seu GitHub (exemplo: `escala-senac`).
2. Faça o upload do arquivo `index.html` para a raiz do repositório.
3. Acesse **Settings** (Configurações) > **Pages**.
4. Em **Branch**, selecione `main` (ou `master`) e salve.
5. Em 1 ou 2 minutos, o seu site estará no ar no link oficial do GitHub Pages!

## ✨ Recursos

- **Visualização Horizontal:** Das 07:45 às 21:00 em blocos de 15 minutos.
- **Alertas Automáticos:** Destaca em vermelho faltas no balcão (< 2 pessoas) ou conflitos de almoço simultâneo (≥ 2 pessoas).
- **Lançamento por Calendário:** Agende Férias e Licenças selecionando o período de datas. Todas as guias do mês são atualizadas instantaneamente.
- **Modo Print Screen:** Oculta menus para captura rápida da tela (Win + Shift + S).
- **Auto-salvamento:** Guarda as edições localmente no navegador (`localStorage`) com opção de exportar/importar backup JSON.
